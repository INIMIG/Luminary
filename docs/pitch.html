理解檢查
為什麼深海生物可以把紅色當作隱身斗篷？
A. 因為海水會優先吸收紅光
B. 因為紅光在海水中傳播最快
C. 因為深海生物普遍會發出紅光
After

原本選擇題保留 + 新增「追問與練習」面板

選擇題沒拿掉，下面加一個面板，使用者可以自由打字或按 🎤 用語音問。兩個模式：

追問與練習
追問答題
為什麼紅色在深海會變黑？
詢問🎤
紅蝦的紅色是「反射紅光」才看得到。八百米深處幾乎沒有紅光，沒得反射，於是它把殘餘的藍綠光也吸光，看起來就接近黑色。
答題模式
追問答題

✓ 答對了

③ 場景視覺強化 · Cinematic Bloom

Before

3D 模型已經是 GLB（你之前就做好了）

這部分的 GLB swap 你早就把 createExternalActor() 寫好了，模型已經在用 counter-fish.glb、predator-shark.glb、crawfish.glb、glub-evolved.glb。我沒重做。

但是發光的部分原本只是純色點光源，沒有 glow halo，魚腹的「反向照明」看起來不夠戲劇化。

無 bloom · 點光源
After

加上 UnrealBloomPass + 加密霧

所有發光元素都會自然 bloom（魚腹、紅光、紅燈、星光）。Fog 從 5–22 縮成 4.5–20，水下霧感更強。

應急：如果在 demo 機上 frame rate 變差，按 Shift+B 可以即時關掉 bloom。

Bloom + Fog · cinematic
實作：Three.js EffectComposer + RenderPass + UnrealBloomPass。失敗時自動 fallback 回直接渲染，不會 crash。

怎麼跑 · How to run

  1. 把 feature/luminary-enhancements 拉下來：git fetch origin && git checkout feature/luminary-enhancements
  2. 複製 .env.example 為 .env，填入 OPENAI_API_KEY（INIMIG 那邊用 openai-next.com 的 key 沒問題，你用自己的或共用的都可以）
  3. 跑 python run_demo.py ──瀏覽器自動開啟
